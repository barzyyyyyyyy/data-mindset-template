Part 1 · GitHub

Your own copy of the platform, published as your site.

1

Sign in to GitHub

At github.com: sign in, or create a free account.

2

Make your own copy (a "fork")

  1. Open the course repository: github.com/asafbarzilay-web/data-mindset-template
  2. Click Fork (top right, circled below), then Create fork.

GitHub can take several minutes, showing "Forking…". Refreshing doesn't help: wait until the page changes.

a repository named your-name/data-mindset-template, with "forked from…" under its name. This is yours: every later step happens there.

Working as a group? One of you forks, then Settings → Collaborators → Add people.

3

Publish your site

  1. Open your fork: github.com/your-name/data-mindset-template (it says "forked from…" under its name).
  2. Click Settings (last tab), then Pages (left menu).
  3. Under Build and deployment: Source Deploy from a branch, branch main, folder / (root). Click Save.
  4. Wait a minute and refresh.

"Your site is live at https://your-name.github.io/data-mindset-template/". That's your site.

If Pages says "Upgrade or make this repository public", you're not on your fork.

Part 2 · Supabase

Your database, where everything is recorded.

4

Create a project

  1. At supabase.com, sign in (with GitHub is easiest).
  2. First time? It asks for an organization: your own name, Personal, Free.
  3. Click New project:
    Name: data-mindset
    Password: Generate a password, and save it
    Region: Central EU (Frankfurt)
    Leave Enable Data API ticked; the other boxes don't matter.
  4. Click Create new project and wait a minute or two.

the project's home page, with its address https://….supabase.co near the top.

5

Create the tables

  1. Click here, on this page:
    Not Supabase's own Copy next to the address: you'll use that one in step 8.
  2. In Supabase, open the SQL Editor (left sidebar, the >_ icon). Click New query, paste (⌘V), Run. If it warns about destructive operations, confirm: it only creates what's missing.

a small result table listing sessions, clicks, selections, identities.

6

Create your sign-in for the dashboard

  1. In the left sidebar: Authentication → Users → Add user → Create new user.
  2. Your email and a password you choose. Keep Auto Confirm User ticked, then Create user.

your email in the list of users.

Part 3 · Claude

Your AI assistant, connected to your platform.

7

Set up your assistant in the cloud

No Code tab, or no Cloud option? Your plan doesn't include Claude Code.

A · Open the form
  1. In the Claude app: Code → + New.
  2. Click Local (above the message box) → Cloud → Add cloud environment…

a form with boxes for a name, network access and environment variables.

B · Name it, open the network
  1. Name: Data-mindset.
  2. Network access: Full.
C · Add your secret key
  1. In the form's Environment variables box, first the name: click
    then paste it (⌘V) into the box.
  2. Now the key. In Supabase (another tab): Project Settings → API Keys → Secret keys. Copy the key named default, come back, and paste it right after the =:
    SUPABASE_SECRET_KEY=sb_secret_…
  1. Click Add environment.

This is the password your assistant uses to build in your database. It lives only in this form: never paste it in the chat.

the chip above the message box now says Data-mindset.

D · Pick your repository
  1. Click + Select repository…, next to Data-mindset.
  2. First time only: Connect GitHub and sign in, then install the Claude GitHub App and allow data-mindset-template.
  3. Pick your-name/data-mindset-template (Refresh list if needed).

above the message box: Data-mindset · data-mindset-template · main.

Next time you click + New, pick Data-mindset again from the cloud chip: it's your environment.

8

Register for the course

  1. In the message box, type: "Register me for the course".
  2. Your assistant asks three things, one at a time:
    Your nameas your lecturer knows you
    Supabase project URLOn your project's home page, click Copy next to the address: a list opens. Click Project URL.
    Publishable keySame list: click Publishable key (starts with sb_publishable_).

it says your details are saved.

Never paste the secret key here. If you do, your assistant tells you how to replace it.

Until you register, your lecturer can't see you or open lessons for you.

9

Your assistant checks everything

Right after step 8, it checks your setup by itself, one line each:

  1. database setup: step 5 ran
  2. analysis is readable: your dashboard can read your views
  3. capture works: a test visit is written and found
  4. your assistant can build: step 7's key works

ALL GOOD, then "Reported to your lecturer: setup done." If a line says FAIL, it tells you which step to redo.

Then open your dashboard (it gives you the link) and sign in with step 6's email and password.

your dashboard, and your first lesson: lesson 0, with the link to its slides.

Every time: Code → + New, pick Data-mindset on the cloud chip, then ask "What are we working on?"

That's it. Every lesson now starts from your home page, and your assistant from + New in the Claude app.
